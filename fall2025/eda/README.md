# Fall 2025 EDA

Archived Fall 2025 exploratory data analysis scripts. These performed
initial dataset profiling, column analysis, and visualization of the
raw incident data before the Spring 2026 pipeline was designed.

## Files

| File | Purpose |
|------|---------|
| `main.py` | Entry point for EDA pipeline |
| `consolidated_eda.py` | Combined analysis script |
| `dataFeatures.py` | Feature engineering and column statistics |
| `dataModifier.py` | Data cleaning and transformation utilities |
| `dataVisualizer.py` | Visualization generation |
| `column_definitions.json` | Schema reference for raw CSV columns |
| `charts/` | Generated chart outputs |
| `visualization/` | Additional visualization outputs |
| `data_clean/` | Intermediate cleaned data |
